# 🌳 Eco AI System
### *Your Smart Guide to Nature Conservation (AI/ML Hackathon Project)*

Eco AI System is an interactive educational application designed to connect people with nature and foster environmental responsibility. By uploading or taking a photo of a tree, flower, or plant, the system uses computer vision to instantly identify the species and generate adaptive educational content tailored for both children and adults.

## 🚀 Core Features
- **Instant AI Plant Recognition:** Identifies local species from images.
- **Adaptive Age Modes:** 
  - **👶 Kids Mode:** Uses engaging storytelling, simple vocabulary, and emphasis on animal habitats.
  - **🧔 Adults Mode:** Provides scientific data, chemical composition, and practical conservation statistics.
- **Environmental Alert System:** Highlights the "ecological superpower" of each plant and explicitly details the devastating consequences of deforestation and climate damage.
- **💬 Interactive Chat Interface:** Allows users to ask continuous, real-time follow-up questions about the analyzed species in both English and Romanian.

## ⚙️ Tech Stack & Architecture
- **Language:** Python 3.10+
- **Frontend / UI:** Streamlit (Responsive web interface optimized to look like a mobile application).
- **Core Engine:** Pre-trained Computer Vision Models & API integration (Plant.id / Kindwise).

## 🗂️ Project Structure
- `app.py`: The main execution script containing the UI layouts, responsive components, adaptive botanical database, and the interactive conversational AI logic.
- `README.md`: Technical documentation and project overview for the Hyperbloom Hackathon jury.
