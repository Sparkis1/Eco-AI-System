# 🌳 Eco AI System
### *Your Smart Guide to Nature Conservation (AI/ML Hackathon Project)*

Eco AI System is an interactive educational application designed to connect people with nature and foster environmental responsibility. By uploading or taking a photo of a tree, flower, or plant, the system uses computer vision to instantly identify the species and generate adaptive educational content tailored for both children and adults.

## 🚀 Core Features
- **Instant AI Plant Recognition:** Identifies trees (like the Oak) and flowers (like the Snowdrop) from uploaded images.
- **Adaptive Age Modes:** 
  - **👶 Kids Mode:** Uses engaging storytelling, friendly emojis, and emphasis on animal habitats.
  - **🧔 Adults Mode:** Provides scientific names, chemical compound details, and conservation metrics.
- **Environmental Alert System:** Highlights the "ecological superpower" of each species and details the devastating consequences of deforestation, uprooting, and climate damage.
- **💬 Continuous Chat Interface:** Features a conversational AI chatbot allowing users to ask real-time follow-up questions about nature in English.

## ⚙️ Tech Stack & Architecture
- **Language:** Python 3.10+
- **Frontend / UI:** Streamlit (Responsive web interface optimized to double as a web platform and a mobile app mockup).
- **Core Engine:** Conceptual framework prepared for Pre-trained Computer Vision Models & LLM API integration.
